# 📊 오늘의 진짜 정보판 (ALEPH T04 - Real Information Board)

외부 원천 데이터가 지연되거나 실패할 때도 **마지막 정상값을 안전하게 보존하고 현재 상태를 사용자에게 정직하게 설명**하는 반응형 정보 대시보드입니다.

---

## 🌟 주요 기능 및 설계 원칙

1. **매일 궁금한 단일 공개 지표 (카드 1)**
   - **지표**: 서울 실시간 기온 (`°C`)
   - **출처**: [Open-Meteo Weather API](https://api.open-meteo.com/v1/forecast?latitude=37.5665&longitude=126.9780&current=temperature_2m)
   - **화면 표시**: 값, 단위, 출처, 출처 시각, 조회 시각, 기준 시간대 (`Asia/Seoul`, KST)를 한 화면에서 확인
   - **무결성 검증 (T04-C10)**: 외부 원천 수신 원자료(JSON) · 로컬 스토리지 일별 저장값 · 화면 UI 표시값이 100% 일치하도록 설계

2. **비밀키 없는 호출 (카드 2 - T04-C11)**
   - API 키 발급이 불필요한 비개인 공개 원천을 사용하여 클라이언트 코드, Git 커밋 기록, 네트워크 요청 어디에도 비밀키 원문이 노출되지 않습니다.

3. **5가지 외부 실패 합성 재생 & 복구 (카드 3)**
   - ALEPH T04 공인 결정론적 Fixture 9종 완벽 탑재:
     - ⏱️ `T04-TIMEOUT`: 느린 외부 응답 (timeout)
     - 🔒 `T04-AUTH-401`: 외부 데이터 원천 거절 (auth)
     - 🚦 `T04-RATE-429`: 외부 원천 호출 제한 (rate_limit)
     - 📡 `T04-OFFLINE`: 네트워크 오프라인 (offline)
     - 💥 `T04-SCHEMA-BREAK`: 응답 데이터 형식 변조 (schema_error)
   - **마지막 정상값(Last Known Good) 보존**: 실패 시 이전 정상값이 지워지지 않고 유지됨
   - **오래된 값(stale) 표시**: 정상값 옆에 stale 배지와 에러 종류별 사용자 조치 안내 표시
   - **회복(T04-RECOVER-D2)**: [다시 시도] 시 `fresh / none` 상태로 복구 및 2행(+15pt) 추가 완료

4. **하루 한 줄 보존 (카드 4)**
   - `Asia/Seoul` 날짜를 고유 키(`signal_id + record_date`)로 삼아 당일 여러 번 조회해도 기존 행을 원자적으로 갱신하여 하루 1건을 유지합니다.
   - 자정이 지나 다음 날짜가 되면 새 일별 행이 자동으로 생성됩니다.

5. **실제 이틀과 어제 대비 (카드 5)**
   - 저장된 일별 기록들을 날짜순으로 정렬하여 전일 대비 증감 및 변화량(delta)을 원자료로부터 정확하게 재계산하여 표시합니다.

## 📋 짧은 확인 방법 4줄 (T04-C27)

1. **위치:** 배포된 URL 접속 후 첫 화면에서 실시간 서울 기온 카드 확인, 상단 [2. 9종 합성 시험 패널] 탭 클릭
2. **행동:** ① [T04-NORMAL-D1-B] 클릭 → ② [T04-TIMEOUT] 클릭 → ③ [T04-RECOVER-D2] 클릭
3. **통과 모습:** D1-B에서 105pt 확인, TIMEOUT 시 105pt가 유지된 채 `stale / timeout` 배지와 지연 안내가 표시됨, RECOVER-D2 클릭 시 120pt로 복구되며 `fresh / none`, 2건 보존(+15pt)으로 전환됨
4. **안 될 때 모습:** 실패 시 이전 정상값이 지워져 `--` 또는 0으로 바뀌거나, stale 표시가 없거나, 복구 버튼을 눌러도 fresh 상태로 돌아오지 않음
